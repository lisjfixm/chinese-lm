對話模式

chat

你打字，Qwen 回一句。保留最近數輪對話作為上下文，可隨時清除重來。

你好，想問什麼就打一句，我接著寫。
回答由選定的 Qwen 後端即時產生；候選詞機率僅 Ollama 後端提供。

字元的座標

embedding map

座標取自 Qwen2.5-7B 參考字向量（3584 維，PCA 壓到二維）。語義相近的字在圖上通常比較近，已對應 。點任一點，可把該字帶入操作台的提示詞。

座標是 PCA 二維投影，只保留兩個主方向；原本的語義關係比這張平面圖更豐富。

它能做到什麼，做不到什麼

limits

短暫對話記憶

對話保留最近數輪作為上下文，可一鍵清除重來；上下文長短由後端模型本身決定。

候選詞機率

操作台候選分布由 Ollama logprobs 提供前 10 名；Web 後端（WebLLM）此版本不回傳候選機率，會顯示不支援註記。

權重不在 HTML 內

Qwen 權重保留在後端：Ollama 本機端或瀏覽器 WebGPU 快取；單一 HTML 只內嵌字元座標與圖表庫，不內嵌模型權重。

座標是投影

字元地圖的二維位置是 Qwen 參考嵌入的 PCA 投影，只保留兩個主方向；平面上的遠近不等於語義上的全部關係。

輸出有上限

示範生成限制在約一百餘字，長文會在到達上限時截斷；溫度與 top-k 只取操作台滑桿的數值，不代表後端模型的全部取樣能力。

示範生成走 Qwen2.5：本機 Ollama（localhost:11434）或瀏覽器 WebGPU（WebLLM）；字元座標取自 Qwen2.5-7B 參考嵌入 PCA 投影。
